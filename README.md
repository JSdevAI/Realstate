# André Araújo Real Estate - Next.js Port

Este projeto foi portado para **Next.js 15 (App Router)** para compatibilidade com o ambiente Antigravity e deploy facilitado na Vercel.

## Funcionalidades Mantidas
- **Hero Scroll Motion**: Animação de frames de alta fidelidade no scroll.
- **Design Original**: Estilos preservados integralmente usando Tailwind 4.
- **Galeria e Filtros**: Navegação e filtros de imóveis preservados.

## Como Executar Localmente

1. **Instalar dependências**:
   ```bash
   npm install
   ```

2. **Executar em desenvolvimento**:
   ```bash
   npm run dev
   ```

3. **Gerar Build de Produção**:
   ```bash
   npm run build
   ```

## Deploy na Vercel
1. Conecte este repositório à Vercel.
2. Certifique-se de que o **Root Directory** está definido como `Site_Realstate`.
3. O Framework Preset deve ser detetado automaticamente como **Next.js**.
4. Clique em **Deploy**.
